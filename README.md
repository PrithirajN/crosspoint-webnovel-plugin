# Web Novels for CrossPoint

A [CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) plugin that searches Royal Road, Scribble Hub and AO3 (Archive of Our Own), downloads a web novel or work as an EPUB, and later adds only the new chapters to that same EPUB.

## Install

- **Plugin Hub:** install *Web Novels* from the **Community Plugins** list.
- **By hand:** download `webnovel-v*.zip` from [Releases](../../releases/latest), unzip it, and copy the `webnovel` folder to `/plugins/` on the reader's SD card.

The plugin itself lives in [`webnovel.crosspoint-plugin/`](webnovel.crosspoint-plugin/). See its [README](webnovel.crosspoint-plugin/README.md) for how to use it.

## Credits
